# Research workflow

1. Encode scope, period, geography, source quality, and exclusion rules in the Task objective and criteria.
2. Use one step for corpus inventory before synthesis.
3. Record source receipts with title, organization, publication date, event date, URL, limitations, and supported claims.
4. Treat duplicated reporting of one primary source as one piece of evidence.
5. Separate facts, interpretations, conclusions, contradictions, and unknowns.
6. Add a gap-search step after the first evidence map.
7. Require citation audit receipts for key conclusions.
8. Promote only stable findings; do not save search snippets or temporary hypotheses as memories.
