# ADR-001: Слои графа

Дата решения: 2026-04-15. Статус: accepted.
Статус реализации сверён с исходниками 2026-09-05.

## Контекст и решение

Близкие названия графовых пакетов скрывают разные обязанности. Сохраняем
отдельные границы для алгоритмов, конкретного Neo4j-клиента и интерфейса
хранилища, чтобы изменение backend не требовало переписывать алгоритмы.

| Пакет | Обязанность |
|---|---|
| `pkg/graph` | Алгоритмы над структурами в памяти: dedup, triplets, multiquery; без persistence |
| `pkg/graphdb` | Neo4j I/O, Cypher, соединения и конкретные операции backend |
| `pkg/graphstore` | `GraphStore` и адаптеры графового хранения, включая SQL для SQLite/PostgreSQL и Neo4j |

Разделение алгоритмов и I/O сохраняет возможность независимо тестировать их.
Интерфейс хранилища даёт общую точку для обходов, чтения, путей и записи; он не
является сам по себе границей авторизации.

## Текущая реализация

`pkg/graphstore` уже используется: SQL-чтение и поиск путей подключены в части
HTTP-обработчиков, memify использует интерфейс для записи. Поэтому прежнее
описание «мёртвый код без импортёров» больше не действует. Миграция не завершена
для всех путей: прямые обращения к `graphdb` и SQL ещё существуют.

См. [интерфейс](../../pkg/graphstore/store.go),
[SQL-адаптер](../../pkg/graphstore/sql.go),
[Neo4j-адаптер](../../pkg/graphstore/neo4j.go),
[поиск пути](../../internal/http/api_graph_path.go) и
[memify](../../internal/http/memify.go).

## Правила дальнейших изменений

Чистый алгоритм размещается в `pkg/graph` или соответствующем специализированном
пакете. Neo4j-протокол остаётся в `pkg/graphdb`; общие операции хранения и
адаптеры — в `pkg/graphstore`. При переводе существующего обработчика на
интерфейс сохраняются его scope, temporal-фильтры, ошибки и wire-контракт.
Не добавляем новый конфигурационный переключатель только ради этого ADR.

SQLite и PostgreSQL проверяются на одних фикстурах, включая ошибки и откат
записи. Для Neo4j нужны отдельные проверки реального backend; отсутствие сервиса
не считается успешной проверкой паритета. Сравниваются семантика путей,
временная валидность, результаты записи и ошибки, а не только число строк.

Авторизация узлов, рёбер и их концов, а также provenance производных данных
остаются обязанностью конкретного пути. Наличие `GraphStore` не доказывает
изоляцию всех графовых API или полное удаление документа. Текущие ограничения:
[документы](../document-management.md); проверки: [testing](../testing.md).

## Отклонённые альтернативы

Объединение алгоритмов с Neo4j-клиентом смешало бы вычисления и I/O. Удаление
интерфейса потеряло бы общий контракт и SQL-реализацию. Полный одномоментный
перевод всех обработчиков увеличил бы риск изменения поведения; миграция
выполняется по подтверждённым путям с регрессионными тестами.
